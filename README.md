# Agent School

A small React learning app that introduces self-learning agents with a three-step loop and an interactive reward-based demo.

## Run locally

```bash
npm install
npm run dev
```

## Component folders

- `src/components/basics/` explains the observe, act, and learn loop.
- `src/components/lab/` contains a tiny two-action reward-learning simulation.

The lab uses randomized rewards and an incremental average to estimate how useful each strategy is. It is an educational toy example, not a trained or general-purpose AI model.
